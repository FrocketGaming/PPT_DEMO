deckgen reference

Every option for every component, with defaults and examples. For advice on what to put on a slide, see “Building a good slide” in the README.

uv sync
uv run deckgen configs/demo.yaml              # -> out/demo.pptx
uv run deckgen configs/demo.yaml -o my.pptx   # build to a specific file
uv run deckgen layouts "Brand Template"       # list a template's layouts and placeholders
CommandWhat it does
deckgen <config.yaml>Build the deck to ./out/<config name>.pptx
deckgen <config.yaml> -o <file.pptx>Build to a specific file
deckgen layouts "<template>"List a template's layouts and placeholder numbers. Takes a name in ./templates/ or a path

Each build writes a fresh .pptx, so edits made in PowerPoint are lost on the next build. The YAML is the source of truth. Close the deck in PowerPoint before rebuilding, because Windows locks open files.

Example configs to copy from:

  • configs/demo.yaml: a short tour of the main components
  • configs/recipes.yaml: one slide per common use case
  • configs/demo_advanced.yaml: a full business review with dashboards, scorecards and small multiples
  • configs/demo_branded.yaml: the demo built on a brand template

Config shape

A config has four top-level keys. Only slides is required.

deck:                          # file-wide settings, see "deck"
  title: FY2026 review
  theme: {primary: "#1F3A5F", accent: "#E07A5F", font: Calibri}

data:                          # named data sources, see "Data sources"
  monthly: ../data/monthly_sales.csv

defaults:                      # options applied to every component of a type
  chart: {font_size: 11}

slides:
  - type: title                # title | section | content (default) | closing
    title: FY2026 review
    subtitle: Revenue, product and customers

  - title: Revenue beat target in 11 of 12 months
    subtitle: Monthly revenue vs. target
    source: monthly_sales.csv
    notes: Speaker notes go here.
    left:  {type: insights, items: [December alone was **$276K**]}
    right: {type: chart, kind: line, data: monthly, x: month, y: [revenue, target]}

A config mistake stops the build with a message naming the slide and the problem, for example slide 4 ('Revenue beat target'): region 'right': column(s) ['revnue'] not in 'monthly'. See Errors and fixes.

Regions and stacks

A content slide places components in named regions. Use any combination, or full on its own.

+-----------------------------+
|            top              |   size = fraction of the height (default 0.3)
+---------+---------+---------+
|  left   | center  |  right  |   size = relative width (default 1)
+---------+---------+---------+
|           bottom            |
+-----------------------------+
Regionsize meansDefault
left, center, rightRelative width. left: {size: 1} and right: {size: 2} give a 1/3–2/3 split1
top, bottomFraction of the content height, when there is a middle row. Without one, they split the height by relative size0.3
fullThe whole content area. Cannot be combined with other regions

Put size on the component itself (right: {type: chart, size: 2, …}) or on the stack. Regions are separated by the slide's gap (default 0.3 inches).

Stacks

To put several components in one region, use stack. Each item's weight is its share of the region's height. Items are 0.2 inches apart.

left:
  size: 1
  stack:
    - {type: kpis, weight: 1, items: [...]}
    - {type: insights, weight: 2, items: [...]}

You can also group regions under one key: regions: {left: …, right: …}. It does the same thing.

Any option that takes a colour (color, panel, background, a progress bar's color) accepts a theme colour name or a hex code.

Bold and line breaks

Wrap text in double asterisks to make it bold and accent-coloured: "December alone was **$276K**". This works in titles, subtitles, footnotes, insights, text, quote, KPI labels and notes, timeline, agenda and cycle text, table cells and placeholders.

WhereNew lineNew paragraph
textNot supported; a single line break becomes a spaceA blank line
insightsNot supportedEach item is a paragraph
cycle center\n (in double quotes)
Placeholders\n (in double quotes)A list: [line, line]

Text with a colon followed by a space, or starting with *, [, {, # or &, must be quoted in YAML: - "**Risk:** the pilot is small".

Which format goes where

deckgen uses two kinds of format string. Components drawn by deckgen use Python formats. Charts are native PowerPoint charts, so they use Excel number formats.

OptionKindExample
kpis → format, delta_formatPython"${:,.0f}"
progress → formatPython"{:.0%}"
table → formatsPython{revenue: "${:,.0f}"}
chart → number_format, axis_format, label_formatExcel'$#,##0,"K"'

Without a format, numbers are shown with thousands separators: whole numbers as-is (1,234), decimals to two places (1,234.50). Text is shown unchanged.

Python formats

For KPI values and deltas, progress bars and table cells.

The value goes where the {} is. Anything outside the braces is printed as-is, so "${:,.0f}" puts a dollar sign in front and "{:.1f}x" puts an x after. Always quote the format in YAML.

Cheat sheet

FormatValueShowsUse for
"{:,}"12345671,234,567Counts
"{:,.0f}"1234567.891,234,568Large numbers, no decimals
"${:,.0f}"1234567.89$1,234,568Money
"${:,.2f}"1234.5$1,234.50Money with cents
"{:.1f}"3.141593.1One decimal place
"{:.0%}"0.52352%Fractions as percentages
"{:.1%}"0.52352.3%Percentages with a decimal
"{:+.0%}"0.523+52%Changes, with the sign
"{:+,}"4200+4,200Changes in counts
"{:.1f}x"5.3915.4xMultiples, such as return on spend
"{:.1f}h"3.463.5hUnits after the number
"{:.0f} pts"6.26 ptsPoints

How a format is built

Inside the braces, after the colon, the parts go in this order. All are optional.

PartExampleMeaning
+{:+.0%}Always show the sign, including + for positive numbers
,{:,}Thousands separator
.N{:.2f}Decimal places (with f or %)
f{:.1f}Fixed-point number
%{:.0%}Multiply by 100 and add a percent sign

% multiplies by 100. Use it on fractions: 0.52 shows as 52%. If your data already holds 52, use "{:.0f}%" instead.

Python cannot scale to thousands or millions. "{:,.0f}K" on 276400 shows 276,400K. Store the value in thousands in the data, or type the KPI as a literal (value: "$276K"). Charts can scale, see Excel number formats.

Numeric formats fail on text. format: "{:,}" on a literal such as "Holiday Blitz" or "+4.2%" stops the build. Leave format off for literal text.

Halves round to even. "{:.0f}" shows 2.5 as 2 and 3.5 as 4.

KPI deltas

The delta is formatted first, then deckgen reads the sign: text starting with - gets ▼, anything else gets ▲. The + or - itself is removed, because the arrow shows the direction. So delta_format: "{:+.0%}" on −0.12 shows ▼ 12%.

The colour comes from the direction and higher_is_better: up is positive and down is negative, or the other way round when higher_is_better: false.

Excel number formats

For chart → number_format, axis_format and label_format.

These are the same codes as Excel's Format Cells → Custom. number_format sets both the axis and the data labels. axis_format and label_format override one of them. Quote them with single quotes in YAML, so that double quotes inside stay intact.

FormatValueShowsNotes
General276400276400Default
'#,##0'276400276,400Thousands separator

'$#,##0,"K"'276400$276KEach trailing comma divides by 1,000
'$#,##0.0,,"M"'1250000$1.3MTwo commas divide by 1,000,000
'0%'0.52352%Multiplies by 100
'0.0%'0.52352.3%
'0.0"x"'5.3915.4xText goes in double quotes
'+0%;-0%;0%'−0.12-12%Positive; negative; zero
'#,##0;(#,##0)'−4200(4,200)Accounting-style negatives

A stacked_column_100 or stacked_bar_100 chart's axis defaults to 0%. A waterfall's data labels get a + or - added for increases and decreases, and hide zeros.

Data sources

Name each source under data. A source is a CSV path, relative to the config, or a list of rows written inline.

data:
  monthly: ../data/monthly_sales.csv
  targets:
    - {region: North, target: 400000}
    - {region: South, target: 250000}

In CSVs, cells that look like numbers become numbers, and thousands separators are allowed (1,234). Everything else stays text. The first row is the header.

Percent signs and currency symbols make a cell text. 12% and $400 are not numbers, so they cannot be summed, charted or formatted. Store 0.12 and 400, and add the symbol with a format.

Queries

Charts, tables and computed metrics can filter, group, sort and trim a source before using it. The keys are applied in this order.

KeyExampleMeaning
where{region: West}
{region: [West, North]}		Keep rows that match every column given. A list matches any of its values
group_byregion
[region, quarter]		One row per group. Number columns are combined with agg; other text columns are dropped
aggsumHow group_by combines numbers: sum (default), mean, count (rows per group), min, max
sort_byrevenueSort by one column, smallest first
descendingtrueSort largest first
limit5Keep the first N rows. With sort_by and descending, this is the top N
# top five campaigns by revenue, as a bar chart
{type: chart, kind: bar, data: campaigns, x: campaign, y: revenue,
 sort_by: revenue, descending: true, limit: 5}

Groups and categories keep the order in which they first appear in the data, unless you sort.

Computed metrics

A KPI value or delta, and a progress bar's value, max or target, can be computed from the data instead of typed in. This keeps the number correct when the data changes.

value: {source: monthly, column: revenue, agg: sum}
KeyDefaultMeaning
sourcerequiredData source name
columnrequiredColumn to compute from
aggsumHow to turn the column into one number, see below
group_aggsumWith group_by: how rows are combined within each group, before agg
where, group_by, sort_by, descending, limitThe query keys, applied first

agg values

aggResult
sumTotal
meanAverage
countNumber of rows
min, maxSmallest, largest
first, lastThe value in the first or last row
growthRelative % change from the first row to the last: (last − first) / first, as a fraction. 100 → 150 gives 0.5, which "{:+.0%}" shows as +50%

first, last and growth follow row order. They use the rows as they appear in the CSV, or as sorted by sort_by. Make sure the data is in time order.

growth fails if the first value is 0, because it divides by it.

There is no agg for the absolute difference (last − first). Type it as a literal: delta: "+$94,400".

Examples

# total for one region
value: {source: regional, column: revenue, where: {region: West}}

# December vs January, as a percentage
delta: {source: monthly, column: revenue, agg: growth}

# Q4 total vs Q1 total: sum each quarter, then compare the first and last quarters
delta: {source: regional, column: revenue, group_by: quarter, agg: growth}

# change in the monthly average response time
delta: {source: support, column: first_response_hours, group_by: month, group_agg: mean, agg: growth}

# best campaign's return on spend
value: {source: campaigns, column: roas, agg: max}

numbersection (built-in look)Large faint numeral on the right, e.g. "02"
tagcontentChapter label, in a template's tag box or in the footer with deck.footer.chapter. Defaults to the latest section title
layoutall (template only)Use this template layout instead of the profile's default
placeholdersall (template only)Fill the layout's numbered boxes, see Placeholders
datetitleOverrides deck.date for this slide

Any other key stops the build with a list of the valid ones. This catches typos such as subtitel.

Placeholders

With a brand template, placeholders: fills a layout's boxes by number. Find the numbers with uv run deckgen layouts "<template>".

ValueResult
"text"Text with the template's styling. \n starts a new line
[line, line]One paragraph per item, with the template's bullet style
{text: …, font_size: 14}Styled text. Also bold, italic, color, align. Only what you set is overridden
{type: chart, …} (any component)The component, drawn where the placeholder sits
{type: image, path: …} in a picture placeholderThe image, cropped to fill the placeholder
- title: Revenue beat target
  layout: Diagram/Chart with Text
  placeholders:
    25: {text: "Revenue beat target in **11 of 12** months", font_size: 20}
    26: [First point, Second point]
    27: {type: chart, kind: column, data: monthly, x: month, y: revenue}

Placeholders you leave empty are removed, so no “Click to add text” prompts are left behind.

Template profile

templates/<name>.yaml, next to the template, sets the default layout per slide type, which placeholder holds each role, and where regions go.

slides:                                  # title, section, content, closing
  title:
    layout: Presentation Title Cool Gray # a name from `deckgen layouts`
    title: 10                            # placeholder number per role
    subtitle: 11
    date: 12
  content:
    layout: Content Slide – Title Only
    title: 22
    tag: 21
content_area: [0.44, 1.6, 12.47, 5.1]   # x, y, width, height in inches
theme:                                   # overrides colours read from the template
  palette: ["1F4456", "E8542C", "448790"]
KeyMeaning
slides.<type>.layoutLayout name. Matching ignores case, extra spaces and – vs -
slides.<type>.title / subtitle / date / tagPlaceholder number for that role
content_areaWhere regions are laid out. Without it, the space between the title and any footer bar
themeSame keys as deck.theme

Without a profile, layouts are guessed from names such as “Title Slide”, “Section Header”, “Title Only” and “Thank You”.
